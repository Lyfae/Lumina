# Contributing to Lumina

Thank you for your interest in contributing to Lumina!

This document is a work in progress. As the project matures, this guide will be expanded with clear contribution guidelines.

## Current Status

Lumina is currently in active solo development. The core architecture (especially the Wallpaper Manager and per-monitor system) is still evolving rapidly.

Until the project reaches a more stable state, large contributions may be difficult to integrate. Small bug fixes, documentation improvements, and thoughtful discussion are always welcome.

## How to Contribute

### Reporting Issues

- Use the GitHub Issues tab.
- Please include:
  - macOS version
  - Steps to reproduce
  - Relevant console output (especially from `⌘D` → Debug: Print Status)
  - Whether you're running a debug or release build

### Pull Requests

Until further notice, please open an issue first before submitting a pull request for anything beyond small fixes. This helps avoid duplicated effort while the architecture is still fluid.

### Code Style

- Follow modern Swift 6 conventions.
- Prefer clarity over cleverness.
- Keep UI copy friendly for users of all technical levels.
