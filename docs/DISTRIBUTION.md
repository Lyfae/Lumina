# Distribution Guide

Everything you need to build, sign, notarize, and ship Lumina.

---

## One-Command Build

```bash
./scripts/build-dmg.sh
```

Produces `dist/Lumina-0.1.0.dmg` — a drag-to-install DMG with a proper `.app` bundle, `Info.plist`, icon, and resource bundle. No Xcode project required.

| Variable | Default | Purpose |
|---|---|---|
| `VERSION` | `0.1.0` | `CFBundleShortVersionString` |
| `BUILD_NUMBER` | `1` | `CFBundleVersion` |
| `ARCH` | `arm64` | `arm64`, `x86_64`, or `universal` |
| `SIGN_IDENTITY` | *(empty)* | `"Developer ID Application: Name (TEAMID)"` |

```bash
# Signed universal binary
ARCH=universal SIGN_IDENTITY="Developer ID Application: Paul (XXXXXXXXXX)" \
  VERSION=0.1.0 ./scripts/build-dmg.sh
```

---

## What the Script Does

1. **`swift build -c release`** — hardware-optimised release binary (Apple Silicon uses native arm64 hardware encode/decode throughout)
2. **Assemble `Lumina.app`**:
   - `Contents/MacOS/Lumina` — the executable
   - `Contents/Resources/Lumina_Lumina.bundle` — SPM resource bundle (icons, assets)
   - `Contents/Resources/AppIcon.icns` — converted from PNG via `iconutil`
   - `Contents/Info.plist` — bundle ID, version, `LSUIElement=true`, entitlements keys
3. **`codesign`** — with `--options runtime` and `--timestamp` if `SIGN_IDENTITY` is set
4. **`hdiutil create`** — compressed UDZO DMG with Applications symlink and install instructions

## Code Signing

You need a **Developer ID Application** certificate for Gatekeeper-transparent distribution outside the App Store.

```bash
# List available identities
security find-identity -v -p codesigning

# Sign manually (the script does this automatically)
codesign --force --options runtime \
  --sign "Developer ID Application: Your Name (TEAMID)" \
  --entitlements dist/Lumina.entitlements \
  --timestamp \
  dist/Lumina.app
```

Minimal entitlements (generated by the script):

```xml
<dict>
    <key>com.apple.security.files.user-selected.read-write</key><true/>
    <key>com.apple.security.files.bookmarks.app-scope</key><true/>
    <key>com.apple.security.cs.allow-jit</key><true/>
</dict>
```

## Notarization

Required for Gatekeeper to allow the app on systems that haven't explicitly trusted you.

```bash
# 1. Store credentials once
xcrun notarytool store-credentials "AC_PASSWORD" \
  --apple-id "you@example.com" \
  --team-id "YOURTEAMID" \
  --password "app-specific-password"   # generate at appleid.apple.com

# 2. Submit and wait
xcrun notarytool submit dist/Lumina-0.1.0.dmg \
  --keychain-profile "AC_PASSWORD" \
  --wait

# 3. Staple the ticket
xcrun stapler staple dist/Lumina-0.1.0.dmg

# 4. Verify
spctl --assess -vv dist/Lumina-0.1.0.dmg
```

## DMG Layout

The resulting DMG presents:

```
┌─────────────────────────────────────┐
│   Lumina.app   →   Applications     │
│      [icon]         [folder]        │
│                                     │
│   Install Lumina.txt                │
└─────────────────────────────────────┘
```

User experience: open DMG → drag app → done. Three seconds, no installer.

## Releasing on GitHub

1. Tag the commit: `git tag v0.1.0 && git push origin v0.1.0`
2. Create a GitHub Release from the tag
3. Upload `dist/Lumina-0.1.0.dmg` as the release asset
4. Write release notes (what's new, bug fixes)

---

## Checklist

- [ ] `swift build -c release` passes with no errors
- [ ] App launches correctly from the assembled bundle
- [ ] Signed with Developer ID Application
- [ ] Notarized and stapled
- [ ] `spctl --assess -vv Lumina.app` → "accepted"
- [ ] DMG mounts cleanly on a fresh macOS install
- [ ] Version bumped in `build-dmg.sh` or via `VERSION=` env var
- [ ] GitHub Release created with DMG uploaded

## Future: Sparkle Auto-Update

Once v1.0 ships, add [Sparkle](https://sparkle-project.org) for in-app update checks:

```swift
// Package.swift dependency
.package(url: "https://github.com/sparkle-project/Sparkle", from: "2.0.0")
```

Sparkle checks a hosted `appcast.xml` on launch and offers a seamless "install and relaunch" update flow — no App Store required.
